## Sobre

O Radar de Trafego Orbital simula satelites se movendo em uma grade 2D e
monitorados em tempo real. O objetivo e identificar o par de pontos mais
proximo usando a tecnica de Dividir e Conquistar (Closest Pair of Points).

Quando dois satelites ficam abaixo de uma distancia limite, o sistema emite
um alerta e destaca o par na tela. O usuario pode digitar a letra do satelite
para desviar sua rota durante a simulacao.

## Instalacao

Linguagem: Python<br>

### Pre-requisitos

1. Python 3.10+

### Passo a passo

1. Clone o repositorio:

```bash
git clone https://github.com/projeto-de-algoritmos-2026/G11_Dividir-e-Conquistar_PA-26.1.git
```

2. Entre na pasta do projeto:

```bash
cd G11_Dividir-e-Conquistar_PA-26.1
```

3. Execute o simulador:

```bash
python3 main.py
```

## Uso

1. Execute o programa e observe o radar sendo atualizado.
2. Quando aparecer um alerta, digite a letra do satelite para desviar a rota.
3. Para sair, use `sair`, `q` ou `quit`.

## Outros

- O algoritmo de Closest Pair esta em `closest_pair.py`.
- A simulacao e a interface de terminal estao em `main.py`.
